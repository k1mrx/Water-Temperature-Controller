# Water-Temperature-Controller
A water temperature control system based on a PID controller using Arduino and Python.  The project demonstrates real-time temperature acquisition, PID control, data logging, signal filtering, and performance analysis.

## Features

- Real-time temperature acquisition
- PID controller implementation
- Arduino-based hardware control
- Python data visualization
- FFT analysis
- Temperature logging

- ## Hardware

- Arduino Uno
- NTC Thermistor
- Heating Element
- Power Supply

- ## Software

- Python
- Arduino IDE
- MATLAB (optional)
